# Winter environment assets

The following assets are redistributed under CC0 1.0. They are bundled locally;
playing the game makes no requests to Poly Haven.

- **Snow 02**, Rob Tuytel, Poly Haven: https://polyhaven.com/a/snow_02
  - `snow-diffuse.jpg`: 2K diffuse map
  - `snow-normal.jpg`: 2K OpenGL normal map
  - `snow-roughness.jpg`: 2K roughness map
- **Snowy Forest Path 02**, Oliksiy Yakovlyev, Poly Haven:
  https://polyhaven.com/a/snowy_forest_path_02
  - `winter-forest.hdr`: 2K HDR environment

License: https://creativecommons.org/publicdomain/zero/1.0/
Poly Haven license information: https://polyhaven.com/license

`vendor/addons/loaders/RGBELoader.js` is from Three.js r164, MIT licensed,
matching the vendored Three.js runtime. Source:
https://github.com/mrdoob/three.js/blob/r164/examples/jsm/loaders/RGBELoader.js

The character meshes and animation clips under `models/` predate this overhaul;
no new character models are redistributed by this change.
